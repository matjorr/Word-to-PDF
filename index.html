Frequently asked questions

Which files can I convert?

This first version supports Microsoft Word .docx files. Older .doc files are not supported.

Are my documents uploaded?

No. The conversion runs in your browser. The document is not sent to a conversion server by this page. The required conversion libraries are loaded from a third-party CDN.

Will the PDF look exactly like Word?

Document rendering can vary between browsers and fonts. Review the PDF before using it, especially if your document has complex tables, columns, headers, footers, or unusual fonts.
